一、总体架构

太玄经卜卦系统的核心是一个 三进制 体系，与《易经》的二进制（阴阳两爻）不同，太玄经使用 一、二、三 三种基本画数。

34 = 81 首  ·  每首 9 赞  ·  共 729 赞

卜卦分为两阶段，合计 六揲（六次操作），对应经文"六算而策道穷也"：

阶段一：四揲定首

方（第1揲）→ 州（第2揲）→ 部（第3揲）→ 家（第4揲）
每揲得 1-3，四位组合确定 81 首中之一

阶段二：两揲定赞

赞高位（第5揲）→ 赞低位（第6揲）
(高位-1)×3 + 低位 = 赞位（1-9）
确定该首下九赞中的具体位置

三、揲蓍法（签策法）完整流程

揲蓍法 使用33根签策模拟传统蓍草占卜，是太玄经最正统的卜卦方法。

3.1 单次揲蓍算法（singleYang）

每次揲蓍从33策出发，经过挂一、初揲、再揲三步操作，最终得到 7→1, 8→2, 9→3 的映射。

1
别一：从33策取1策挂于左手小指
剩余：33 - 1 = 32策
2
中分其余：将32策随机分为两组（左组L + 右组R = 32）
3
以三搜之（初揲）：两组各除以3取余
余数规则：0记为3，即余数 ∈ {1,2,3}
左余 = L mod 3（0→3），右余 = R mod 3（0→3）
合计 = 左余 + 右余 ∈ {2, 5}（因 32 mod 3 = 2）
4
并余于艻：移除余数策
剩余 = 32 - 合计 → 30策（余2时）或 27策（余5时）
5
再揲：剩余策再分两组，各除以3取余
合计 ∈ {3, 6}（因 30和27均被3整除，余0记3）
移除后剩余 = 30-3=27 或 30-6=24 或 27-3=24 或 27-6=21
6
数其余：剩余策 ÷ 3
27 ÷ 3 = 9 → 值 = 3
24 ÷ 3 = 8 → 值 = 2
21 ÷ 3 = 7 → 值 = 1

四条可能路径

路径挂一初揲余再揲余剩余÷3映射值
A→32232793
B→32262482
C→32532482
D→32562171

3.3 揲蓍法伪代码

function divineBySticks(rng = Math.random):
    // 阶段一：四揲定首
    fang = singleYang(rng)      // 方 1-3
    zhou = singleYang(rng)      // 州 1-3
    bu   = singleYang(rng)      // 部 1-3
    jia  = singleYang(rng)      // 家 1-3

    shouIdx = shouIndex(fang, zhou, bu, jia)

    // 阶段二：两揲定赞
    zanHigh = singleYang(rng)   // 赞高位 1-3
    zanLow  = singleYang(rng)   // 赞低位 1-3
    zanPos  = (zanHigh - 1) * 3 + zanLow  // 1-9

    return buildResult(shouIdx, zanPos, { method: "sticks" })


function singleYang(rng):
    sticks = 33
    sticks -= 1                           // 别一：挂1策

    // 初揲
    left  = randomInt(1, sticks - 1, rng)
    right = sticks - left
    remL  = mod3special(left)    // 0→3, 否则原值
    remR  = mod3special(right)
    sticks -= (remL + remR)     // 移除余数（2或5）

    // 再揲
    left  = randomInt(1, sticks - 1, rng)
    right = sticks - left
    remL  = mod3special(left)
    remR  = mod3special(right)
    sticks -= (remL + remR)     // 移除余数（3或6）

    // 数其余
    result = sticks / 3            // 7, 8, 或 9
    return result == 7 ? 1 : result == 8 ? 2 : 3

四、硬币法完整流程

硬币法 使用3枚硬币，掷6轮（每轮得1-3），结构与揲蓍法完全一致。

4.1 单次掷币映射规则

每枚硬币：正面(阳)记1，背面(阴)记0。三枚合计 yangCount ∈ {0,1,2,3}。

阳数组合概率映射值说明
0阴阴阴1/81全阴，取低位
1阳阴阴/阴阳阴/阴阴阳3/81一阳二阴
2阳阳阴/阳阴阳/阴阳阳3/82二阳一阴
3阳阳阳1/83全阳，取高位
映射设计说明：0-1阳→值1，2阳→值2，3阳→值3。概率分布 P(1)=4/8, P(2)=3/8, P(3)=1/8，近似揲蓍法的路径分布。

4.2 硬币法六轮流程

1
第一轮（3币）→ 值1-3 → 方
2
第二轮（3币）→ 值1-3 → 州
3
第三轮（3币）→ 值1-3 → 部
4
第四轮（3币）→ 值1-3 → 家
↓ → 计算首序号 → 查81首名
5
第五轮（3币）→ 值1-3 → 赞高
6
第六轮（3币）→ 值1-3 → 赞低
↓ → 赞位 = (赞高-1)×3 + 赞低
✓
完成：共掷18枚硬币 → 首名 + 赞位 + 吉凶

4.3 硬币法伪代码

function divineByCoins(rng = Math.random):
    // 六轮掷币，每轮3枚硬币
    r1 = singleCoinToss(rng)    // → {value, coins, yangCount}
    r2 = singleCoinToss(rng)
    r3 = singleCoinToss(rng)
    r4 = singleCoinToss(rng)
    r5 = singleCoinToss(rng)
    r6 = singleCoinToss(rng)

    shouIdx = shouIndex(r1.value, r2.value, r3.value, r4.value)
    zanPos  = (r5.value - 1) * 3 + r6.value

    return buildResult(shouIdx, zanPos, { method: "coins" })


function singleCoinToss(rng):
    coins  = [randBool(rng), randBool(rng), randBool(rng)]
    yang   = countTrue(coins)        // 0-3
    value  = yang <= 1 ? 1 : yang == 2 ? 2 : 3
    return { value, coins, yangCount: yang }

五、首序号计算公式

5.1 正向计算（方州部家 → 首序号）

来自《太玄数》"推玄算"原文：

首序号 = (方-1)×27 + (州-1)×9 + (部-1)×3 + 家

各位权重表

位值1时值2时值3时原文
家+1+2+3"家一置一，二置二，三置三"
部+0+3+6"部一勿增，二增三，三增六"
州+0+9+18"州一勿增，二增九，三增十八"
方+0+27+54"方一勿增，二增二十七，三增五十四"

验证示例

中首（首1）：方1州1部1家1 → 0+0+0+1 = 1 ✓

乐首（首25）：方1州3部2家3 → 0+18+3+3 = 24（去中之数），即第25首 ✓

养首（首81）：方3州3部3家3 → 54+18+6+3 = 81 ✓

5.2 逆向计算（首序号 → 方州部家）

fang = floor((index - 1) / 27) + 1
zhou = floor((index - 1) % 27 / 9) + 1
bu   = floor((index - 1) % 9  / 3) + 1
jia  = (index - 1) % 3 + 1

六、赞位计算与昼夜规则

6.1 赞位计算

赞位 = (赞高位 - 1) × 3 + 赞低位   （范围 1-9）
赞全局序号 = (首序号 - 1) × 9 + 赞位   （范围 1-729）

6.2 九赞位置定义

赞位名称类别层级五行
1初一思下（思内）水
2次二思中（思中）火
3次三思上（思外）木
4次四福下（福小）金
5次五福中（福中）土
6次六福上（福大）水
7次七祸下（祸生）火
8次八祸中（祸中）木
9上九祸上（祸极）金

6.3 昼夜规则

经文："以昼夜别其休咎焉"——逢昼为休（吉），逢夜为咎（凶）。

首类型昼赞（吉）夜赞（凶）规则
阳首（奇数序号）1,3,5,7,92,4,6,8阳首以奇赞为昼
阴首（偶数序号）2,4,6,81,3,5,7,9阴首以偶赞为昼
判定逻辑： 首序号为奇数→阳首，赞位为奇→昼(吉)，赞位为偶→夜(凶)；首序号为偶数→阴首，赞位为偶→昼(吉)，赞位为奇→夜(凶)。 
function zanDayNight(shouIdx, zanPos):
    yinYang = shouIdx % 2 == 1 ? "阳" : "阴"
    isOdd   = zanPos % 2 == 1
    if yinYang == "阳":
        return isOdd ? "昼" : "夜"
    else:
        return isOdd ? "夜" : "昼"

七、四占解读体系

经文："占有四：或星，或时，或数，或辞。"——占断需综合四个因素。

7.1 四占要素

要素来源说明程序化方式
星五行赞位对应五行（水/火/木/金/土），与首德相比ZAN_WUXING[zanPos]
时时令占卜时的季节，与首的节气位置相比getTimeFactor()
数昼夜赞的昼/夜属性，昼=从(吉)，夜=违(凶)zanDayNight()
辞赞辞该赞的赞辞与测辞文本getZanCi() / getZanCe()

7.2 表经纬系统

经文："旦则用经，夕则用纬。"——根据占卜时间选择不同的"表"（参照组）。

表类型适用时辰包含赞位程序化判定
经旦（早晨）1, 5, 7zanPos ∈ {1,5,7}
纬夕（傍晚）3, 4, 8zanPos ∈ {3,4,8}
杂中（午间/夜间）2, 6, 9zanPos ∈ {2,6,9}

7.3 三从三违吉凶判定

取当前表中的3个赞位，判断各自的昼/夜（从/违），按六种模式判定吉凶：

模式含义吉凶建议
一从二从三从三皆从大休大吉，宜行
一从二从三违前吉后凶始中休终咎宜早行
一从二违三违初吉后凶始休中终咎中末宜慎
一违二从三从先凶后吉始咎中终休宜待时
一违二违三从先凶后吉始中咎终休终得安
一违二违三违三皆违大咎大凶，不宜行
function judgeFortune(result):
    states = []
    for i in 1..9:
        states[i] = zanDayNight(shou.index, i) == "昼" ? "从" : "违"

    // 取当前赞所在表的3个状态
    biaoType = result.biao.type
    if biaoType == "经": group = [states[1], states[5], states[7]]
    if biaoType == "纬": group = [states[3], states[4], states[8]]
    if biaoType == "杂": group = [states[2], states[6], states[9]]

    pattern = buildPattern(group)  // 如 "一从二从三从"
    return FORTUNE_MAP[pattern]
